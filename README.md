# نظام المصادقة الطلابي

تطبيق Flutter تجريبي باللغة العربية، مبني على MVC مع Repository Pattern، ويحتوي على شاشات تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور وتعيين كلمة مرور جديدة.

## البنية

- `lib/models/`: نماذج المستخدم والطلبات والنتائج.
- `lib/repositories/`: عقد المستودع وتنفيذ محاكاة الشبكة داخل الذاكرة.
- `lib/controllers/`: إدارة حالة المصادقة باستخدام `ChangeNotifier`.
- `lib/utils/`: مدققات نماذج نقية.
- `lib/views/auth/`: الشاشات ومكوّنات واجهة المصادقة.

## التشغيل والاختبار

```shell
flutter pub get
flutter run
flutter test
```

لا يعتمد التطبيق على حزم تشغيل خارجية. الحسابات مؤقتة وتُحذف عند إغلاق التطبيق؛ المستودع الحالي محاكاة تعليمية وليس خدمة مصادقة إنتاجية. رمز التحقق التجريبي هو `123456`، ويظهر عند طلب إعادة تعيين كلمة المرور.
